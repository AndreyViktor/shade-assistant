Data: 2026-11-23. Estado: `DONE` para uso local conforme D022.

## Resultado parcial

- Foi adicionado um contrato IPC fechado para rechecagem e abertura explícita de três destinos allowlisted dos Ajustes do macOS.
- O helper possui um modo `--readiness` que consulta microfone, preflight de gravação de tela, Speech e a própria assinatura sem iniciar captura nem aceitar comandos de sessão.
- A central em Preferências identifica o helper consultado e explica que a atribuição TCC pode variar entre helper, Electron, Terminal ou IDE no desenvolvimento. A consulta e a abertura de Ajustes permanecem ações explícitas.
- A limitação da API pública de screen capture é mostrada: um preflight falso não diferencia primeira solicitação de uma negativa anterior.
- A identidade informa se há identificador de equipe; esse dado, isoladamente, não comprova Developer ID nem notarização.
