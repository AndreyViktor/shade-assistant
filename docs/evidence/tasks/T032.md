## Testes automatizados e gates

- Testes focados: `createMainWindow.test.ts` + `securityBaseline.test.ts`, **9/9 aprovados**. Cobrem opções explícitas da janela, handlers de permissão/navegação/popup, CSP, lock/integridade, `Info.plist`, ausência de dependência Swift externa e política de assinatura.
- `npm run verify`: lint, formato, três typechecks e build aprovados; **948 Vitest aprovados, 19 skipped**; runner **19/19**. A primeira passagem parou no lint dos novos mocks/matcher tipados como `any`; a correção adicionou tipos explícitos, sem suppressions, e a repetição completa passou.
- `npm run verify:swift`: **57 testes Swift aprovados** e build release aprovado. Inclui preflight antes de captura, fila limitada/fail-closed, sanitização, framing, cancelamento, cleanup, ausência de input e lifecycle de duas fontes.
- `npm run test:helper`: bundle release reconstruído, `Info.plist` válido, assinatura estrita válida e **16/16 testes de processo aprovados**, sem captura. O script emitiu `HELPER_SECURITY_BASELINE_OK identifier=local.meetingcopilot.transcriber signature=adhoc-runtime entitlements=none`.
- `npm run test:smoke`: **30/30 aprovados em 3,4 min** com Electron 45.4.1, perfil temporário, helper/Responses sintéticos, rede bloqueada e captura negada. Inclui isolamento real do renderer, CSP, popup bloqueado, lifecycle/reload, ausência de segredo no renderer e `safeStorage` real com valor sintético.
- `npm audit --json`: zero vulnerabilidades info/low/moderate/high/critical. `git diff --check`: aprovado após a implementação e repetido depois do fechamento documental.

## Ensaio Mac autorizado sem dados sensíveis

O ensaio não iniciou captura e não pediu nem alterou TCC:

1. `npm run probe:swift` consultou o Mac real e reportou `scope=capability-spike-no-capture`, Speech disponível, `microphone=authorized` e `screenCapturePreflight=true`. Não instalou assets; pt-BR/en-US permaneceram `assetsRequired` nesse probe.
2. O helper foi reconstruído e executado somente contra comandos/JSONL sintéticos. `plutil`, designated requirement e verificação estrita passaram.
3. `codesign -d --verbose=4` confirmou Mach-O arm64, identifier estável, ad hoc + runtime e ausência de Team ID. `codesign -d --entitlements -` não retornou plist de entitlements.
4. O smoke iniciou o app real com captura bloqueada e rede guardada; não houve chave real, fala, áudio, screenshot de reunião, API paga, push ou deploy.

O estado TCC consultado pertence ao ambiente atual e não prova qual entrada aparecerá após primeiro prompt/rebuild. Nenhuma fala ou áudio foi necessário para o aceite desta baseline.

## Limites preservados

- Não houve captura física nova, reset de TCC, falha induzida do SO nem inspeção universal de helper órfão. Os testes comprovam cleanup cooperativo/sintético e os casos de lifecycle existentes; não eliminam falha excepcional do kernel/framework.
- Assinatura ad hoc não é Developer ID, notarização, staple nem identidade estável. O pacote real, nested code, `Info.plist` externo e Mac limpo pertencem a T034; fuses, ASAR e auditoria pós-pacote pertencem a T072.
- A consulta de advisories é um snapshot de 2026-11-23 e deve ser repetida em atualizações. `verify` continua offline e não substitui advisory scan futuro.
- STT remoto e screenshot continuam adiados e não foram usados como dependência nem declarados seguros por esta tarefa.
